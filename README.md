# COURIER HELPER 5.2.2 — TEST Android project

**Исходный архив 5.2.1 и точный HTML интерфейс 5.2.2 недоступны.** Этот проект — восстановленная тестовая версия с новым автономным интерфейсом, НЕ точная копия прежней сборки.

## Содержимое
- Самостоятельное приложение `com.courierhelper.app.readerbeta` с кнопкой начала/конца смены, счётчиком HH:MM, учётом заработка, расходов, заказов, локальной целью по заработку и историей.
- GPS foreground service с уведомлением и локальным накоплением расстояния. **Требует проверки в реальном телефоне**: точность, фоновые ограничения, батарея, сброс данных.
- Вручную включаемое плавающее окно Android.
- Экспериментальная Accessibility-служба фильтрует события Glovo и читает только видимый текст; сохраняет только сумму и километры, НЕ принимает заказы.
- Экранный офлайн-тест вымышленных чисел. Реальное распознавание Glovo НЕ подтверждено.
- Старые данные GitHub Pages НЕ импортируются автоматически, копировать/удалять старую установку нельзя.

## GitHub Actions
1. На GitHub в репозитории создайте ОТДЕЛЬНУЮ ветку `courier-test-5-2-2`, базовую ветку не заменяйте.
2. Распакуйте ZIP на компьютере. Загрузите **содержимое** папки проекта (включая скрытую `.github`) в корень тестовой ветки. Убедитесь, что файл `.github/workflows/android-apk.yml` появился.
3. Откройте Actions → `Build Courier Helper APK`. Если кнопка Run workflow недоступна из-за расположения workflow только в тестовой ветке, используйте push-триггер ветки либо сначала включите Actions для репозитория.
4. Выберите тестовую ветку → Run workflow, скачайте artifact `COURIER-HELPER-5.2.2-TEST-APK`, установите `app-debug.apk`.

**Ограничение:** компиляцию APK в этом окружении выполнить нельзя: отсутствуют Android SDK и Gradle. GitHub Actions должен подтвердить компиляцию; до этого ZIP — исходники, а не готовый APK.
